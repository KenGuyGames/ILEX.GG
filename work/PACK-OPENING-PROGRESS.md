# Pack opening — October 15, 2026

Kenneth selected a pack simulator with rare-pull shine and odds slightly better than physical packs. Implemented as isolated pack-model.js + packs.js + packs.css, registered after existing UI in index.html. Released as version 1.8.0. Engine unchanged from DP/Platinum release.

Scope: 103 validated standard English expansion profiles, Base/Neo/Legendary/e-Card, EX, DP/Platinum, HGSS, BW1–10, XY, SM1–12, SWSH1–12 and SV01–10. Special products with unmodeled collation (including Legendary Treasures), kits/promos, Pocket and unknown/newer profiles remain excluded rather than assigned misleading default packs. Contents and precise model percentages are displayed per set. See ui/PACK-SOURCES.md for sources, known approximations, baseline estimates and booster-pool boundaries.

A 1.12 multiplier applies to each upgrade tier (12% relative, not 12 percentage points). Remainder is removed from ordinary rare probability. Fixed pack size and slot positions are retained. Modern Double/Ultra, Illustration/SIR/Hyper and ACE SPEC use separate slots/pools; subsets have a dedicated parallel-slot pool. Independent packs, uniform within a modeled rarity tier, no physical print-sheet or box guarantees. Only Base holo baseline is documented; unpublished other set rates are explicitly design estimates. Regular-scan reverse finish is a labeled simulation, not new reverse scans or a completed reverse-card library.

Opening persists cards, per-finish counts and totals before revealing; partly revealed packs survive navigation and restart without reroll. Save failure rolls back the full opening. Separate collection with pagination, reveal-next/all, right-click zoom and inspectors; rarity shine, chase glow, hover replay and reduced motion. Pack activity doesn't change decks, library card access or saved match journals. Pack navigation restores full sidebar/menu music after leaving a match.
