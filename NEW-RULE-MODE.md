# New Rule mode

In Play, choose a format and decks, then select **Alternate Mode → New Rule · 96 Cards** before starting the match. For a private match, the host selects **Alternate Mode → New Rule · 96 Cards** before creating the invite. Both players need this build. Existing matches keep their original mode.

The shared deck starts with all 96 supplied New Rule cards and no active rules. Reveal one before the first turn and before each later turn, before normal turn draw. At five active rules, the incoming player chooses which rule to replace. Both players can use active rules; once-per-turn limits are tracked separately for each player. Repeatable rules remain available while they have legal targets and resources.

Use the compact shared-rule strip or **Shared Rules** to inspect and use cards. **Rule Deck** shows all 96 images. On Android in landscape, open **Match controls → Shared Rules**; the controls stay in that drawer to preserve the visible hand. Tap a rule image to enlarge it.

Discarded rules reshuffle when the shared deck runs out. Active rules and attached Vessel of Life stay out of that shuffle. Vessel of Life attaches as a Tool and frees its shared slot; when it leaves play it returns to the separate rule discard. It does not enter an ordinary deck, hand, discard pile or Lost Zone.

Confirmed interpretations:

- Teal Dance attaches Basic Energy from hand, then draws one if the attachment succeeds.
- Colress, Hugh, Jessie and James, Karen, and Lysandre's Trump Card resolve once when revealed.
- Cedric Juniper only permits exact printings with verified printed height/length. This build verifies the 69 Base Set Pokémon printings from their scans; other printings remain ineligible until verified. Heights are guessed in feet and inches. No height is inferred from species metadata.
- Parallel City asks the incoming player to choose its initial facing side. Each player may flip it once on their own turn.
- New Rule actions do not consume a Supporter play, ordinary Energy attachment, GX attack or VSTAR Power. Normal card effects and format/cube restrictions still apply. New Rule effects are not Pokémon Abilities; a rule that disables Pokémon Abilities does not disable New Rule actions.

The shared environment and choices replay from the saved match journal. Local and bot Undo use existing immediate Undo; a private opponent must approve Undo. The native New 3DS alpha is unchanged and does not yet include this mode. Physical Android and two-PC internet acceptance were not performed for this update.

Interaction corrections: Scoop Up Block prevents returning damaged Pokémon to hand while still allowing Run Away Draw and Vanishing Wings to shuffle them into the deck. Tandem Unit respects the current Bench limit. Thunder Mountain follows the Pokémon’s current type, including type-changing Abilities and their suppression. Barrier Shrine also blocks paired Stadiums. Older matches retain recorded outcomes and offer corrected actions immediately after loading; Undo starts a corrected new branch.
