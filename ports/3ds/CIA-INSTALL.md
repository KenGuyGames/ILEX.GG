# HOME Menu installation — forest/audio Alpha 3, public starter-only bundle

Target: New 3DS / New 3DS XL / New 2DS XL, with custom firmware and FBI already configured.

1. Extract the full CIA-SD ZIP to the SD root. Preserve match.json/bak and audio.cfg.
2. In FBI, install SD:/cias/ILEX.GG-New3DS-Playable-Alpha.cia, then return to HOME Menu.
3. Keep SD:/3ds/ilex-gg/runtime, art, data and media. Updating only the CIA will not add the forest/audio assets.
4. Play Matches → Base Set starters. SELECT opens volume/mute controls.

Local homebrew title000400000F1E5800, version3. Prior CIA alpha saves share the SD location. Imported-format saves need their private original card modules and will not restore using this starter-only public bundle. Original 3DS/2DS and the latest physical audio/display/performance acceptance remain unverified. See README.md for controls, source and limits.
