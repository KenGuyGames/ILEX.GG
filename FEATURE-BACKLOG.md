# ILEX.GG feature backlog

Requested by Kenneth on October 12, 2026. These are planned features, to implement when Kenneth is ready. Add subsequent feature ideas to this same list; retain existing items and record their status. This list does not authorize beginning implementation now.

- [ ] **Odds checker:** Calculate the probability of starting a selected card in the opening hand and the probability of prizing it. Account for the selected deck and number of copies.
- [ ] **Interactive foil overlay:** Add a foil overlay to cards with holo rarity or higher. Animate the overlay as the mouse moves over a card.
- [ ] **Opponent pile counts:** When hovering over the opponent's deck or discard pile, clearly display the number of cards in that pile.
- [ ] **Online multiplayer:** Allow online play without requiring payment for hosting or other infrastructure. Evaluate feasible approaches and their connection requirements when implementation begins.
- [ ] **Undo Action:** Add an in-game Undo Action feature.
- [ ] **Audio:** Add sound effects and in-game music.
- [ ] **Attack and ability search:** Allow searching the card library by attack name or ability/Pokémon Power name. Requested October 12, 2026.
- [ ] **Actions on an enlarged Pokémon:** Clicking a Pokémon to use an attack or ability opens an enlarged card view. Select the action directly on the card's attack or ability area, such as clicking Damage Swap on Alakazam to activate it. Requested October 12, 2026.

- [ ] **Visual decklists:** Make decklists viewable using card images rather than only lines of text. Requested October 12, 2026.

Current active work: automate the remaining WOTC-era cards with historical rules and validated card interactions. Keep this work separate from the planned features above.
