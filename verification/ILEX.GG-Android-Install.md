# ILEX.GG3.0.0 for Android

Android8+ with a current Android System WebView. Install ILEX.GG-Android.apk over the existing app. Original signing certificate retained; version3.0.0-android.103/code103. Do not uninstall first if you want to keep your local workspace/cache.

Campaign is the first main-menu destination. New Game confirms before replacing current campaign progress; Continue resumes saved dialogue or battle. Text speed and word sounds are under Settings. Export workspace before importing: import replaces the destination workspace. Music, scenery and included scans are bundled; uncached paper scans need internet.

3DS, Pocket and Multiplayer are still in progress. Android networking is unavailable. Physical-device rendering/audio, lifecycle, native file pickers and performance acceptance remain pending.
